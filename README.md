# My Water Tracker

Contents:
- app.py             Streamlit app (deploy on Streamlit Community Cloud)
- requirements.txt   Python dependencies
- index.html         Standalone web version (open in any browser, no install)

Run Streamlit locally:
    pip install -r requirements.txt
    streamlit run app.py

Deploy: push app.py + requirements.txt to GitHub, then create the app at share.streamlit.io (main file: app.py).
